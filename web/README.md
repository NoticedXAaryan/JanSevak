# JanSeva web

Public Next.js site for [JanSeva](../README.md): citizen pages, chat, and institution dashboards.

```bash
npm ci
npm run dev
```

The app runs at http://localhost:3000 and talks to the FastAPI server at `NEXT_PUBLIC_API_URL` (default `http://localhost:8000/api`).

```bash
npm run lint
npm run build
```
